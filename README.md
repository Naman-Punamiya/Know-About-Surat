# Know About Surat

**Know About Surat** is a Flutter application designed to help users explore the city of **Surat, Gujarat**. The app provides information about famous tourist attractions, local food, shopping destinations, historical places, and much more through a clean and user-friendly interface.

Whether you're a tourist planning a visit or a local wanting to discover more about the city, this app serves as a handy guide to everything Surat has to offer.

---

## ✨ Features

* 📍 Explore popular tourist attractions
* 🍛 Discover Surat's famous food and restaurants
* 🛍️ Browse shopping destinations and markets
* 🏛️ Learn about historical and cultural places
* 📱 Simple and intuitive Flutter UI
* 🎨 Clean Material Design interface
* ⚡ Fast and responsive performance

## 🚀 Getting Started

### Prerequisites

* Flutter SDK (Latest Stable Version)
* Dart SDK
* Android Studio or VS Code
* Android Emulator or Physical Device

### Installation

1. Clone the repository.

```bash
git clone https://github.com/Naman-Punamiya/Know-About-Surat.git
```

2. Navigate to the project directory.

```bash
cd Know-About-Surat
```

3. Install dependencies.

```bash
flutter pub get
```

4. Run the application.

```bash
flutter run
```
